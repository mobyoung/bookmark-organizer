# 各浏览器导出书签（非技术步骤）

这是给**终端用户**看的。当用户说"怎么把书签导出来"时，AI 据此用大白话引导。导出后得到一个 HTML 文件，发给 AI 即可。

> 通用提示：导出的是 Netscape 格式书签 HTML，文件名通常是「书签.html」或「bookmarks.html」。它包含所有文件夹和网址，**不影响**浏览器里现有书签。

---

## Chrome（Windows / macOS / Linux）

1. 打开 Chrome。
2. 按快捷键打开书签管理器：
   - **macOS**：`⌘ + ⇧ + O`
   - **Windows / Linux**：`Ctrl + ⇧ + O`
   - 或点右上角 ⋮ → 书签 → 书签管理器。
3. 在书签管理器右上角点 **⋮**（三个点）。
4. 选 **导出书签**。
5. 浏览器会下载一个 HTML 文件（默认在"下载"文件夹）。把它发给 AI。

---

## Microsoft Edge

1. 打开 Edge。
2. 快捷键 `Ctrl + ⇧ + O`（或 ⋮ → 收藏夹）。
3. 右侧收藏夹面板里点 **⋮** → **导出收藏夹**。
4. 选择保存位置，得到 HTML 文件，发给 AI。

---

## Firefox

1. 打开 Firefox。
2. 按 `Ctrl + ⇧ + B`（或 ☰ 菜单 → 书签 → 管理书签）。
3. 在书签库窗口，点顶部 **导入和备份** → **导出书签到 HTML 文件**。
4. 选择保存位置，得到 HTML，发给 AI。

---

## Safari（macOS）

1. 打开 Safari，点 **文件** 菜单 → **导出书签…**（若菜单项是灰的，先打开"显示收藏夹栏"或从一个书签栏状态进入）。
2. 选择保存位置，得到 HTML，发给 AI。

> Safari 也可在 `~/Library/Safari/Bookmarks.plist` 找到原生数据，但导出 HTML 最简单通用。

---

## 导出后

把 HTML 文件通过对话发给 AI（或告诉 AI 它的本地路径）。AI 会接着做分析与整理，**你不需要自己打开或编辑这个文件**。

如果文件很大（上千书签），直接发到对话里、或放在项目目录下告诉 AI 路径都可以。
